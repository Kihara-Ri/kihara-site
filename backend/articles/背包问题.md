背包问题是动态规划中非常经典的一类模型。它的核心问题是：给定若干物品，每个物品有重量和价值，在背包容量有限的情况下，如何选择物品，使得总重量不超过容量，同时总价值最大。

从状态转移的角度看，背包问题关心的是「当前物品选不选、选几次」；从生成函数的角度看，背包问题也可以理解为多项式乘法中某一项系数的含义。


## 0-1 背包

0-1 背包中，每个物品最多只能选择一次。

假设有 $n$ 个物品，第 $i$ 个物品的重量为 $w_i$，价值为 $v_i$，背包容量为 $W$。目标是在总重量不超过 $W$ 的前提下，让总价值最大。

例如：

| 物品 | 重量 | 价值 |
| :--: | :--: | :--: |
| 物品 0 | 1 | 15 |
| 物品 1 | 3 | 20 |
| 物品 2 | 4 | 30 |

背包最大容量为 $4$。

### 二维 DP

定义状态：

$$
dp[i][j]
$$

表示只考虑前 $i$ 个物品，在背包容量为 $j$ 时可以获得的最大价值。

对于第 $i$ 个物品，有两种选择：

- 不选第 $i$ 个物品，价值为 $dp[i - 1][j]$
- 选第 $i$ 个物品，价值为 $dp[i - 1][j - w_i] + v_i$

因此状态转移方程为：

$$
dp[i][j] = \max(dp[i - 1][j], dp[i - 1][j - w_i] + v_i)
$$

如果 $j < w_i$，说明当前容量放不下第 $i$ 个物品，只能不选：

$$
dp[i][j] = dp[i - 1][j]
$$

这个状态转移的本质是：当前层 $i$ 的结果只依赖上一层 $i - 1$。因为每个物品最多只能使用一次，所以选第 $i$ 个物品时，剩余容量 $j - w_i$ 对应的也必须是上一层的结果。

### 一维优化

二维 DP 中，当前状态只依赖上一层，因此可以压缩成一维数组。

定义：

$$
dp[j]
$$

表示容量为 $j$ 时能够获得的最大价值。

状态转移为：

$$
dp[j] = \max(dp[j], dp[j - w_i] + v_i)
$$

代码如下：

```cpp
vector<int> dp(W + 1, 0);

for (int i = 0; i < n; i++) {
    for (int j = W; j >= w[i]; j--) {
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```

这里容量 $j$ 必须倒序枚举。

原因是 0-1 背包中每个物品只能使用一次。如果正序枚举，$dp[j - w_i]$ 可能已经在本轮被当前物品更新过，再用它更新 $dp[j]$，就相当于重复使用了第 $i$ 个物品。

倒序枚举可以保证 $dp[j - w_i]$ 仍然是上一轮物品处理完后的状态。

## 完全背包

完全背包中，每种物品可以选择无限次。

它的转移形式和 0-1 背包很像：

$$
dp[j] = \max(dp[j], dp[j - w_i] + v_i)
$$

区别在于容量 $j$ 要正序枚举。

```cpp
vector<int> dp(W + 1, 0);

for (int i = 0; i < n; i++) {
    for (int j = w[i]; j <= W; j++) {
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```

为什么完全背包要正序？

假设只有一种物品，重量 $w = 2$，价值 $v = 3$，背包容量 $W = 4$。

初始化：

```text
dp = [0, 0, 0, 0, 0]
```

正序枚举容量：

```text
j = 2: dp[2] = dp[0] + 3 = 3
j = 4: dp[4] = dp[2] + 3 = 6
```

这里 $dp[2]$ 已经使用了当前物品，再用它更新 $dp[4]$，正好表示当前物品可以被重复使用。

因此：

| 类型 | 容量枚举方向 | 含义 |
| :--: | :--: | :-- |
| 0-1 背包 | 倒序 | 防止同一物品重复使用 |
| 完全背包 | 正序 | 允许同一物品重复使用 |

## 多重背包

多重背包中，每种物品最多可以选择 $c_i$ 次。

第 $i$ 种物品有：

- 重量 $w_i$
- 价值 $v_i$
- 数量 $c_i$

一种直接做法是枚举当前物品选多少个：

```cpp
vector<int> dp(W + 1, 0);

for (int i = 0; i < n; i++) {
    for (int j = W; j >= 0; j--) {
        for (int k = 1; k <= c[i] && k * w[i] <= j; k++) {
            dp[j] = max(dp[j], dp[j - k * w[i]] + k * v[i]);
        }
    }
}
```

这种做法的复杂度较高：

$$
O(W \sum c_i)
$$

### 二进制拆分

多重背包常用二进制拆分优化。

如果某种物品有 $13$ 个，可以拆成：

```text
1, 2, 4, 6
```

因为：

$$
13 = 1 + 2 + 4 + 6
$$

这样可以把一种多重物品拆成若干个 0-1 物品。

例如某种物品的重量为 $w$，价值为 $v$，数量为 $13$，可以拆成：

| 拆分数量 | 新重量 | 新价值 |
| :--: | :--: | :--: |
| 1 | $w$ | $v$ |
| 2 | $2w$ | $2v$ |
| 4 | $4w$ | $4v$ |
| 6 | $6w$ | $6v$ |

然后对这些拆出来的物品做 0-1 背包即可。

优化后的复杂度约为：

$$
O(W \sum \log c_i)
$$

二进制拆分的关键在于：任意不超过 $13$ 的选择数量，都可以由 $1, 2, 4, 6$ 中的若干项组合出来。

## 计数型背包

有些背包问题不是求最大价值，而是问：

- 能否凑出重量 $x$
- 有多少种方案可以凑出重量 $x$

这类问题可以使用布尔 DP 或计数 DP。

### 判断能否凑出重量

定义：

$$
dp[j]
$$

表示是否可以凑出重量 $j$。

初始化：

```cpp
dp[0] = true;
```

0-1 背包写法：

```cpp
vector<bool> dp(W + 1, false);
dp[0] = true;

for (int i = 0; i < n; i++) {
    for (int j = W; j >= w[i]; j--) {
        dp[j] = dp[j] || dp[j - w[i]];
    }
}
```

状态转移可以写成：

$$
dp[j] \leftarrow dp[j] \lor dp[j - w_i]
$$

### 统计方案数

定义：

$$
dp[j]
$$

表示凑出重量 $j$ 的方案数。

初始化：

```cpp
dp[0] = 1;
```

0-1 背包计数写法：

```cpp
vector<long long> dp(W + 1, 0);
dp[0] = 1;

for (int i = 0; i < n; i++) {
    for (int j = W; j >= w[i]; j--) {
        dp[j] += dp[j - w[i]];
    }
}
```

状态转移为：

$$
dp[j] = dp[j] + dp[j - w_i]
$$

这个式子可以理解为：

- 原来就能凑出 $j$ 的方案，保留
- 如果能凑出 $j - w_i$，那么再加上当前物品，就能凑出 $j$

## 生成函数视角

背包问题也可以从生成函数的角度理解。

对于一个重量为 $w$ 的 0-1 物品，它只有两种选择：

- 不选：贡献 $1$
- 选：贡献 $x^w$

所以这个物品对应的生成函数是：

$$
1 + x^w
$$

如果有重量分别为 $2, 3, 5$ 的物品，那么整体生成函数为：

$$
(1 + x^2)(1 + x^3)(1 + x^5)
$$

展开后，如果 $x^k$ 的系数非零，说明存在一种方案可以凑出重量 $k$。

更进一步，$x^k$ 的系数表示凑出重量 $k$ 的方案数。

比如 $x^5$ 可能来自：

- 选择重量 $2$ 和重量 $3$ 的物品
- 直接选择重量 $5$ 的物品

因此 $x^5$ 的系数就是凑出重量 $5$ 的方案数量。

### 和 DP 的关系

0-1 背包的计数转移是：

$$
dp[j] = dp[j] + dp[j - w_i]
$$

这本质上等价于不断乘上：

$$
1 + x^{w_i}
$$

也就是：

$$
f(x) \leftarrow f(x)(1 + x^{w_i})
$$

每处理一个物品，就相当于把当前多项式乘上这个物品对应的生成函数。

### 完全背包的生成函数

完全背包中，每个物品可以选择无限次。

对于重量为 $w$ 的物品，可以选择：

```text
0 个、1 个、2 个、3 个、……
```

对应生成函数为：

$$
1 + x^w + x^{2w} + x^{3w} + \cdots
$$

也就是：

$$
\frac{1}{1 - x^w}
$$

因此完全背包整体可以表示为：

$$
\prod_i \frac{1}{1 - x^{w_i}}
$$

从这个角度看，背包 DP 其实是在维护多项式系数。某些计数问题还可以进一步转化为多项式乘法问题，并使用 FFT 或 NTT 优化。

## 总结

背包问题的核心在于状态定义和枚举顺序。

| 类型 | 每个物品可选次数 | 常见转移 | 容量枚举 |
| :--: | :--: | :-- | :--: |
| 0-1 背包 | 0 或 1 次 | $dp[j] = \max(dp[j], dp[j - w] + v)$ | 倒序 |
| 完全背包 | 无限次 | $dp[j] = \max(dp[j], dp[j - w] + v)$ | 正序 |
| 多重背包 | 最多 $c_i$ 次 | 枚举数量或二进制拆分 | 通常转成 0-1 |
| 计数背包 | 统计方案数 | $dp[j] += dp[j - w]$ | 根据题意决定 |
| 生成函数 | 多项式建模 | 系数表示方案数 | 可结合 FFT/NTT |

一句话记忆：

```text
0-1 背包倒序，防止重复使用；
完全背包正序，允许重复使用；
多重背包拆分，转化为 0-1；
计数背包求方案数；
生成函数把背包看成多项式乘法。
```
