# Agent Guide

This repository keeps repeatable AI-agent workflows in `.agents/tasks/`.

When a request matches one of those workflows, read the relevant task guide before editing files. Treat these guides as project-owned procedure: prefer the listed scripts and validation commands over ad hoc edits.

## Task Guides

- `.agents/tasks/music-album-release.md`
  Add albums to the music collection, fetch metadata and cover art, build, commit, push, and deploy when requested.
